📊 GUI Marksheet using Python (Tkinter)

✨ This project is a GUI-based Marksheet application built using Python and Tkinter.
It allows users to enter student details and subject grades, then automatically calculates:

✅ Credit obtained per subject
✅ Total credits
✅ SGPA (Semester Grade Point Average)


🖥️ Technologies Used

🐍 Python 3
🪟 Tkinter (GUI library)


🌟 Features

🎯 User-friendly Graphical Interface
🧑‍🎓 Enter student details:
   ➤ Name
   ➤ Registration Number
   ➤ Roll Number
📚 Enter grades for subjects
🧮 Automatic calculation of:
   ➤ Subject-wise credits
   ➤ Total credits
   ➤ SGPA
🅰️ Supported grades:
   ➤ A, B, C, D, P, F
🖨️ Output can be snapshotted and printed as a semester marksheet


📘 Subjects and Credits

📌 C++   : 4 Credits
📌 PHP   : 4 Credits
📌 DS    : 3 Credits
📌 JAVA  : 4 Credits

🔢 Total Credits = 15


🎓 Grade to Credit Mapping

🅰️ Grade A : 10 points
🅱️ Grade B : 9 points
🅲 Grade C : 8 points
🅳 Grade D : 7 points
🅿️ Grade P : 6 points
❌ Grade F : 0 points

📐 Credit obtained = Grade Point × Subject Credit


📈 SGPA Formula

📊 SGPA = Total Credit Obtained / Total Credits


▶️ How to Run the Project

1️⃣ Make sure Python 3 is installed
   👉 python --version

2️⃣ Clone the repository
   👉 git clone https://github.com/Chandani911/guimarksheet.git

3️⃣ Go to the project folder
   👉 cd guimarksheet

4️⃣ Run the program
   👉 python marksheet.py


🖼️ Output

🪟 A Tkinter window opens
✍️ Enter grades (A / B / C / D / P / F)
🟢 Click Submit
🎉 Total credits and SGPA are displayed instantly
